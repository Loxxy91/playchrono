# Security policy

PlayChrono stores data locally and runs a small read-only HTTP server bound to `127.0.0.1` for the live dashboard.

If you find a vulnerability (for example a way for a website or another device to read a player's stats), please
**do not open a public issue**. Report it privately through
[GitHub security advisories](https://github.com/Loxxy91/playchrono/security/advisories/new).
You will get an answer within a few days, and a fix will be released as soon as possible.
